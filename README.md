# Gatefall Chronicles

一句话简介：这是一个基于《X4: Timelines》的原创隐藏时间线战役，讲述 Xenon 借助异常跃迁技术撕开星门网络，各阵营在文明级危机中从猜忌、内斗逐渐走向联合反攻的故事。

当前公开版本现已包含 **八关完整战役**：

- 《星门陨落01：暗流涌动》
- 《星门陨落02：祸水东引》
- 《星门陨落03：逃出生天》
- 《星门陨落04：同舟共济》
- 《星门陨落05：审判日》
- 《星门陨落06：生命线》
- 《星门陨落07：渺茫的希望》
- 《星门陨落08：罪与罚》

English version: [README_EN.md](README_EN.md)

## 最新更新：最终关《罪与罚》完成

本次更新正式完成《星门陨落08：罪与罚》。至此，`Gatefall Chronicles` 八关主战役全部完成。

最终关直接承接《渺茫的希望》中 `Alternative XIV` 创造出的战略窗口。玩家扮演“悖论号”舰长西格弗里德，率领由 TER、BOR、ANT、HAT、TRI、Split 残部与阳裔民兵组成的联合舰队，从矩阵 #79 发起对野蛮疾驰 I Xenon 跃迁中枢的最后攻势。

主要流程包括：

- 三线指挥联合舰队摧毁 Xenon 能源供给站，解除星门防御与生产设施的能量护盾。
- 部署战术生产平台，恢复第四关的造船、资源补给与舰队组织玩法。
- 在限时压力下摧毁 Xenon 造船厂、船坞，以及能够将反物质炸弹直接跃迁到舰队附近的超级武器。
- 遭遇隐藏跃迁信标触发的 Xenon 战略级伏击，“悖论号”重创并被迫撤退、充能与重新集结。
- 在生产平台失守后转移至 Xenon 能源站残骸，利用残余能量电池维持“悖论号”的储备能源充能。
- 面对 Xenon 重建的生产设施和多座超级武器，利用“悖论号”损毁区域改造出的临时生产能力继续组织护卫舰与航空兵作战。
- 发动第二次强攻，突破矩阵 #79 的星门防御站，并将 Delta Flight、第 86 护卫队、BOR 航空兵与部分联合舰队留在后方牵制 Xenon。
- 最终进入野蛮疾驰 I，执行最后的备用方案并摧毁 Xenon 跃迁中枢，终结“星门陨落”。

最终关英文标题统一为 `Gatefall 08: Hamartia`，并延续对《Mental Omega 3.3.6》盟军最终战 `Withershins / Hamartia`、Epsilon 最终关 `Babel`、Siegfried 与 Paradox Engine 的致敬。任务 8 的英文 L044 也已完成针对性重译与润色。

## 战役保存功能

原版《X4: Timelines》并不原生支持在战役关卡中保存。本 Mod 实现了独立的战役保存与读档系统，允许玩家在关卡途中继续进度。

读取战役存档后，系统会自动恢复当前 Phase 对应的 BGM，避免战斗或剧情音乐在读档后丢失。

## 安装方法

如果你是从 GitHub 获取源码：

1. 下载或克隆本仓库。
2. 将 `extensions/gatefall_chronicles` 整个文件夹复制到 X4 游戏根目录下的 `extensions` 文件夹中。
3. 启动游戏，在扩展菜单中确认 `Gatefall Chronicles` 已启用。

典型目录结构：

```text
X4 Foundations/
└─ extensions/
   └─ gatefall_chronicles/
```

## 如何进入战役

本战役不是普通主宇宙任务，而是通过隐藏 Timelines 场景入口进入。

1. 启动游戏并进入 `Timelines`。
2. 进入 Timelines Hub，也就是玩家常说的“黑色空间”。
3. 找到隐藏战役 / 隐藏场景入口。
4. 打开隐藏战役列表。
5. 在列表末尾找到 `Gatefall Chronicles`。
6. 选择希望游玩的关卡。

如果你已经进入过官方隐藏场景，本 Mod 使用的是同一套场景列表。

主要特点：护卫舰战斗、主力舰引擎破坏、前哨站防守、多阶段分镜与评分。

主要特点：三线舰队指挥、战术生产平台、限时超级武器、跃迁伏击、撤退与重新充能、临时舰内生产、联合舰队总攻、终局主力舰冲锋与完整评分结算。
