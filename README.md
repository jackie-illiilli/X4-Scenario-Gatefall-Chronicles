
# Gatefall Chronicles

一句话简介：这是一个基于《X4: Timelines》的原创隐藏时间线战役，讲述 Xenon 借助异常跃迁技术撕开未来战局，各阵营在灭世危机前被迫重新结盟的故事。

当前公开版本包含六关可完整游玩并结算的战役：

- 《星门陨落01：暗流涌动》
- 《星门陨落02：祸水东引》
- 《星门陨落03：逃出生天》
- 《星门陨落04：同舟共济》
- 《星门陨落05：审判日》
- 《星门陨落06：生命线》

English version: [README_EN.md](README_EN.md)

## 最新更新：《生命线》与战役保存功能

本次更新正式完成第六关《星门陨落06：生命线》，并加入由本 Mod 自行实现的战役内保存功能：

- 指挥奥德修斯改进型“多梅尔III”、四艘老式宙斯航母与四支 Delta 航空队，在第二接触 II 闪点重新打通通往太阳系的生命线。
- 依次保护 TRI、TEL 与 Split 撤离舰队，在持续涌入的 Xenon 主力舰之间完成舰载机拦截、鱼雷突击、紧急抢修与人员转运。
- 与 Rayna 率领的第 86 护卫队会合，摧毁 Xenon 跃迁信标与 CPU 母舰，并掩护最后的 Split 难民船团撤离闪点。
- 完整加入七阶段流程、中英文字幕、多段连续分镜、循环增援、倒计时目标、失败判定和五星评分。
- 最终率领遍体鳞伤的联合舰队抵达月之舟，与赶来的地球干预军会合。
- 新增战役内保存与继续游玩功能；读取战役存档后，当前 Phase 的 BGM 会自动恢复，不会再出现读档后音乐丢失或持续静音的问题。
- 评分由任务完成情况以及 TRI、TEL 撤离舰船的幸存数量共同决定。

## 战役保存功能

原版《X4: Timelines》并不原生支持在战役关卡中保存。本 Mod 现已加入自行实现的战役保存功能，允许玩家在关卡途中保存并继续游玩。

本次版本同时完善了音乐恢复逻辑：读取存档后，系统会重新播放当前阶段对应的 BGM，不会因为保存与读档而丢失战斗音乐或剧情音乐。

## 安装方法

如果你是从 GitHub 获取源码，安装方式如下：

1. 下载或克隆本仓库。
2. 将 `extensions/gatefall_chronicles` 整个文件夹复制到 X4 游戏根目录下的 `extensions` 文件夹中。
3. 启动游戏，在扩展菜单中确认 `Gatefall Chronicles` 已启用。

典型目录结构：

```text
X4 Foundations/
└─ extensions/
   └─ gatefall_chronicles/
```

## 进入游戏的流程

本战役不是普通主宇宙任务，而是通过隐藏时间线战役入口进入。

1. 启动游戏并进入 `时间线（Timelines）`。
2. 进入时间线 Hub，也就是玩家常说的“黑色空间”。
3. 找到 `隐藏战役 / 隐藏场景` 入口。
4. 打开隐藏战役列表。
5. 在列表末尾找到 `Gatefall Chronicles` 的战役入口。
6. 选择希望游玩的关卡。

如果你已经游玩过官方隐藏场景，进入方式基本一致；本 Mod 的战役挂在同一个隐藏战役列表中。

## 当前公开内容

### 战役 01：暗流涌动

当前状态：完整战役已完成，可完整游玩与结算

- 玩家与 TER 盟友僚机前往阿尔特弥斯的朦胧部署远程侦察卫星。
- 调查过程中发现 Kha'ak 巢穴已被摧毁，并出现异常空间折叠信号。
- 玩家被卷入 Xenon 核心区野蛮疾驰，随后突围至 TER 前哨站。
- 坚持到 Terran 干预军战列舰 `TER 典范` 抵达并接管战场。

主要特点：护卫舰战斗、主力舰引擎破坏、前哨站防守、多阶段分镜与评分结算。

### 战役 02：祸水东引

当前状态：完整战役已完成，可完整游玩与结算

- 玩家扮演 Argon 后方指挥官，在希望之歌的选择远程指挥 HAT 第 86 护卫队。
- 通过地图进行 OOS 舰队指挥，处理货船、矿船和空间站遭遇的多点 Xenon 袭击。
- 潜入机密数据库，取得能够改变 Xenon 攻击向量的 Yaki 导航协议。
- 在 Argon 决定牺牲第 86 护卫队后，将 Xenon 主力引向 ZYA 的金氏家族，为护卫队争取逃生机会。

主要特点：站内流程、OOS 远程指挥、多线防守、数据库潜入、导航信标部署与评分结算。

### 战役 03：逃出生天

当前状态：完整战役已完成，可完整游玩与结算

- 玩家扮演一名 Split 女性工程师，驾驶失去动力的角蝰返回菲氏家族，在废墟中接管响尾蛇“菲氏6号”。
- 驰援两座难民工厂，与 Carter、Kat、Jun、Emile 和 Jorge 会合，并确认父母已经登上救援舰“菲氏之秋”。
- 护送救援舰通过 Valka 家族和金氏家族，在主力舰伏击与每分钟一次的 Xenon K 增援中维持撤离路线。
- 面对 Kha'ak 湮灭者“漫漫长夜”的追击，在 Nhuut 家族营救平民，并将废弃反物质单元工厂改造成最终陷阱。
- 根据救援舰结构、菲氏6号结构、Xenon L/XL 击毁数与通关时间进行评分；关键目标被摧毁时立即以 0 星结算。

主要特点：响尾蛇驱逐舰战斗、难民舰护航、小队编队指挥、循环主力舰增援、六阶段剧情演出、动态 BGM、完整失败判定与五星评分。

### 战役 04：同舟共济

当前状态：完整战役已完成，可完整游玩与结算

- 保护打捞船从虹鳉航母残骸中取得异端的终结封锁情报。
- 率领 Boron–Terran 联合舰队摧毁 Xenon 雷达船，解除远程炮击威胁。
- 部署玩家控制的战术生产平台，并通过造船、资源补充和舰队编组推进战线。
- 对 Xenon 供能设施、造船厂、船坞和 M0 发动一场接近 RTS 玩法的完整攻势。

主要特点：大规模舰队战、玩家造船厂、动态资源机制、独立支线目标、循环敌军增援、定制 BGM、完整分镜、失败判定与五星评分。

### 战役 05：审判日

当前状态：完整战役已完成，可完整游玩与结算

- 以 Xenon 视角穿过 Argon 阅兵区，破解通讯与能源设施，并部署战略跃迁信标。
- 指挥 Xenon CPU 母舰，利用任务指令循环组装舰队，形成不依赖普通造船厂的伪 RTS 生产玩法。
- 攻击 Argon 之都的建造船、通讯中枢、造船厂、船坞与行政中心。
- 在星门口建立防御阵地，消灭三波 Argon 远征舰队，并观看四处 Xenon 突袭与 Getsu Fune 的失败信标尾声。

主要特点：潜入与识别规避、任务式舰船生产、CPU 母舰指挥、大规模空间站攻坚、堵门防守、多星区尾声、定制 BGM、失败判定与五星评分。

### 战役 06：生命线

当前状态：完整战役已完成，可完整游玩与结算

- 玩家扮演在闪点大战中失去主力舰队的 Paranid 指挥官多梅尔，率领“多梅尔III”与四艘临时集结的宙斯航母重建防线。
- 通过 Delta 航空队进行小型舰拦截与鱼雷反舰作战，保护 TRI、TEL 与 Split 撤离舰队穿过闪点前往虚空和月之舟。
- 与 Rayna 和第 86 护卫队会合，救援受损的民用运输船，并将幸存者转移到仍能航行的军舰和补给舰上。
- 发现 Xenon 跃迁信标后，集中四支 Delta 编队对不断组装增援的 CPU 母舰发动斩首行动。
- 在最后的 Split 船团抵达后主动放弃闪点，掩护菲氏6号、“菲氏之秋”与联合舰队残部撤往太阳系。

主要特点：航母航空兵指挥、VF-31拦截与VF-29鱼雷突击、多阵营难民船团护送、持续主力舰增援、紧急维修与人员转运、CPU母舰斩首、动态定制BGM、完整失败判定与五星评分。

## 致敬

《星门陨落03：逃出生天》在舰船名称、角色名称和剧情演出上致敬了《光环：致远星》与《光环：战斗进化》，并使用了两部作品的原声音乐。

《星门陨落04：同舟共济》的战役结构与演出致敬了《命令与征服：红色警戒 3》盟军第五关《北海：深不可测的要塞》。本关卡也大量使用了《红色警戒 3》的原声音乐（OST），希望以 X4 的舰队战、基地建设与多阶段任务流程，重现这场经典战役带来的氛围与节奏。

《星门陨落05：审判日》致敬《红色警戒 2》Mod《心灵终结 3.3.6》中的 Epsilon 第 13 关《征服者》（`Epsilon 13: The Conqueror`），并使用了由 Black Ice 9 为 Epsilon 阵营制作的 BGM。

《星门陨落06：生命线》是一场以航母航空兵、移民船团与末日撤离为核心的综合致敬关卡：

- 玩家“多梅尔”、座舰“多梅尔III”，以及四艘航母 Balgray（巴尔格雷）、Lambea（兰贝尔）、Darold（达洛德）和 Schderg（修德格），致敬《宇宙战舰大和号2199》的七色星团战役。
- Delta 中队、VF-31/VF-29 编号，以及 Hayate、Mirage、Arad、Messer 等角色名，致敬《Macross Delta》。本关也大量使用《Macross Delta》的歌曲与 BGM，包括《ワルキューレがとまらない ～without Freyja～》《僕らの戦場》《AXIA～ダイスキでダイキライ～》《GIRAFFE BLUES》《いけないボーダーライン》《綺麗な花には毒がある》《ワルキューレは裏切らない》和《ALIVE～祈りの唄～》等。
- CPU 母舰斩首阶段使用《Macross Frontier》的《ライオン》，也是本关唯一一首来自《Macross F》的歌曲。
- Rayna、Shin 与第 86 护卫队延续了对《86－不存在的战区－》的致敬；ANT 旗舰“Sidonia”致敬《希德尼娅的骑士》；结尾出现的 Takeru Shirogane 则致敬《Muv-Luv》系列。
